# 2^11
### By charlie-map, a 1024 clone

Meet the all new **2^11**! This is a simple Node.js app with HTML / CSS / Vanilla JS frontend.

## Startup

1. Run `npm install` to get the most recent packages.
2. You will need to build the database from scratch via:

```bash
mysql -u root < DB.sql
```

There are no required start states that must be in there to begin with.

3. Run `npm run start` to start the project
4. Go to `localhost:2048` to pull up the page
